# Data

`final_temporal_dataset/` is the prepared chronological dataset used by the final experiments. Training covers June–July 2025, validation covers August 2025, and the completed final holdout covers September 2025.

The directory includes all five historically studied institutions. New modeling is restricted to JPMorgan Chase, Wells Fargo, and Key Bank. Citi and Fifth Third Bancorp data is retained unchanged for auditability and historical reproducibility.

See `final_temporal_dataset/README.md` and `final_temporal_dataset/reports/` for construction, schema, data-quality, leakage, and split documentation.

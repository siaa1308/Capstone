# Legacy model runners

These files are preserved as historical implementation evidence. They predate the corrected TBPTT/final continual-FedAvg protocol and are not active training entry points.

- `local_graphsage.py`: earlier static five-bank GraphSAGE baseline.
- `federated_continual_temporal_graphsage.py`: superseded early federated continual runner.

Their original experiment outputs are under `artifacts/historical/`. They may require optional dependencies or their original import layout; the supported final runners are one directory above.

# Streaming documentation moved

The former command-based VM/federation guide has been superseded by the
[model-weight streaming blueprint](../docs/STREAMING_BLUEPRINT.md).

The planned workflow uses containers and a browser dashboard on Windows and
macOS to transfer existing weight files. It does not start training or aggregation.

**Status: blueprint only.** The dashboard and platform launchers are not yet
implemented. This notice is not a runnable setup guide.

The [previous version of TEAMMATE_WEIGHT_STREAMING.md](https://github.com/siaa1308/Capstone/blob/1294588780ddef3512910accce3b0fc48ee655f4/distributed_federation/TEAMMATE_WEIGHT_STREAMING.md)
is preserved in Git history for reference to the old VM workflow. Its machine-specific
settings and training commands are not the new streaming setup.
